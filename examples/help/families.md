# Families

This is a long list of passerine family names. Three of them can be opened: [Corvidae](corvidae.md), [Hirundinidae](swallows.md), and [Passeridae](sparrows.md). Every other family name is ordinary text. Scroll with the wheel, then hold Shift. A pad combo appears on each name that has a page, including [home](index.md) and [taxonomy](taxonomy.md). The rest of the list stays plain.

The groups those three belong to are on the [taxonomy](taxonomy.md) page. The overview is [home](index.md). Ranks change as lists are split and merged. A missing name may be inside a neighbour. A name you cannot open is missing because this sample has no page for it.
